Here are the two test cases being ran:

Test case 1: The user will book a reservation with a start time at 9:30am on July 22nd and an end time at 2:30pm on July 22nd. This is a valid test case since the duration is exactly 5 hours long (300 minutes).

Test case 2: The user will book a reservation with a start time at 9:30am on July 22nd and an end time at 2:31pm on July 22nd. This is an invalid test case since the duration is 5hrs and 1 min (301 minutes), over 5 hours long.
